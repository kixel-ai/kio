# kio questline

## Goal

Keep kio's living work organized as visible, versioned quests, grouped into milestones ordered by priority.

## Plan

- `m0` holds urgent fixes and broken CI.
- `m1` holds current work, tests, and release hygiene.
- `m2` holds deferred work and items waiting on upstream dependencies.
- `m9` is the lab: internal spikes, prototypes, and formal-verification experiments that touch no published API.
